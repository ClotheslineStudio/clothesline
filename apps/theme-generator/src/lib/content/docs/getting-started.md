# Getting Started

The Theme Generator lets you create and preview Clothesline themes in real time.

## What You Can Do

- Edit role seeds and generate OKLCH ramps.
- Preview components using the live-generated theme.
- Export a CSS theme file and a TypeScript snippet.
- Run contrast checks from the Accessibility tab.

## Basic Flow

1. Open the **Customizer** on the left.
2. Select a role (primary, secondary, etc.).
3. Click a ramp shade swatch to open the color picker and adjust the seed.
4. Review updates in **Preview** and **Ramps**.
5. Copy/download output from the **Code** tab.

:::note
The app applies generated CSS live through an in-page style tag, so changes should appear instantly.
:::
