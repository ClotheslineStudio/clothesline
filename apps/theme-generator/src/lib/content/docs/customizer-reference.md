# Customizer Reference

## Color Palette

Use the role strip to select which role you are editing.

- Role swatches select active role only.
- Shade-row swatches open the picker.
- **Random** randomizes the active role seed.
- **Add seed** creates a new custom role.

## Shade Modes

- **Short** shows steps `50`, `500`, `950`.
- **Extended** shows all configured ramp steps.

## Contrast Mapping

The panel includes:

- **Light Contrast** dropdown
- **Dark Contrast** dropdown

These map semantic contrast references to role-step tokens (for example `primary-50`, `error-950`).

:::info
If you add custom seeds, they are included in role selectors, ramps, snippet output, and CSS output.
:::
